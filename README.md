# Akashic Putnam County TN Courts Connector

Connector for Putnam County TN and Federal MD-TN court data.

This module contains:
- Putnam County TN circuit court connector (TypeScript)
- Putnam County TN criminal court connector (Python)
- Federal MD-TN court connector (Python)
- Data validation and mapping
- Mock data for testing
